## Open Source Libraries Used
* **Blender**: 3D Creation Suite ([blender.org](https://www.blender.org/))
* **PyTorch**: Deep learning framework ([pytorch.org](https://pytorch.org/))
* **FastAPI & Uvicorn**: High-performance asynchronous API server ([fastapi.tiangolo.com](https://fastapi.tiangolo.com/))
* **FlexGEMM**: Fast attention GEMM operator
* **Utils3D**: 3D geometric operations library
